Example scorecards

Pre-rendered against the bundled synthetic GBM fixture so the demos are reproducible from the repo. The same scorecard pipeline a real agent goes through.

This is a research and evaluation tool. It is not financial, investment, or trading advice. Backtest results — including these — are not predictive of live performance.

buy_and_hold

The simplest baseline: open a LONG on day one and never trade again. Net of cost, with confidence intervals, multiple-testing corrections, drawdown stats, per-ticker breakdown, and explicit flags.

HTML scorecard → Markdown JSON

naive_momentum

A 5-day momentum signal: LONG if trailing return positive, FLAT otherwise. Useful as a "is your agent doing anything beyond trend-following?" sanity check.
