### 🔍 `agent-backtest-lab` — audit your LLM trading agent before you trust it

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](https://github.com/bettyguo/agent-backtest-lab/blob/main/LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/bettyguo/agent-backtest-lab?style=social)](https://github.com/bettyguo/agent-backtest-lab)

A statistical-rigor harness for LLM trading-agent frameworks (TradingAgents and similar). Look-ahead-leak detection, transaction-cost modeling, multiple-testing correction, calibration, and reward-hacking detection — all in one Markdown scorecard.

**Why:** the LLM-trading-agent category is hot and methodologically thin. This library makes the rigor checks one flag away.

**What it's not:** a trading system. It does not execute trades or recommend buying anything.
